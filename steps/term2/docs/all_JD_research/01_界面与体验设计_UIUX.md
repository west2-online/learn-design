# 01 界面与体验设计（UI/UX 主线）

> 对应 steps 第二学期「Web UI/UX」「客户端 UI/UX」「游戏 UI/UX」三个锚点岗位。
> 本簇按**场景**组织，每个场景下的 UI（视觉）与 UX（交互/体验）岗位合并为一类：招聘市场上 UI/UX 职责高度融合，同一岗位常同时承担界面视觉与交互设计。
> 无障碍不再单列为岗位，而是并入「职业化初步」的通用能力（见 `职业化初步_能力提升清单.md`）。

## 1. 细分岗位清单（按场景，UI+UX 合并）

### 1.1 通用 / 多端 UI/UX 设计师

- 名称变体：UI 设计师、UI/UX 设计师、UI 视觉设计师、多端/全终端 UI 设计师、B 端 UI 设计师、UI 设计工程师、UI 实习设计师
- 工作重心：跨 Web/App/小程序/后台的界面视觉与交互设计；高保真稿、切图标注、设计还原跟进；设计与交互规范制定
- 细分：B 端（SaaS/后台/管理系统）、C 端、数据可视化后台、展馆互动展项软件 UI

### 1.2 Web UI/UX（产品设计与视觉合并）

- 名称变体：网页设计师、Web UI 设计师、网站设计师、交互设计师（Web 向）、UX 设计师、体验设计师、产品体验设计师
- 细分：
  - 官网与落地页（品牌 VI 延续）、Web 产品 UI、B 端 PC 网站、专题页/H5
  - 交互/体验向：广告商业化交互（百度广告 C/B 端）、工具类产品（邮箱/IM/文档，网易偏好技术背景）
- 高频附加要求：HTML/CSS 了解（官网向）、设计系统/组件库维护、用户研究合作、数据分析、原型与交互文档

### 1.3 客户端 UI/UX

- 名称变体：移动端 UI 设计师、App UI 设计师、手机客户端 UI 设计师、iOS/Android UI 设计师、鸿蒙 UI 设计师、智能硬件 UI 设计师、交互设计师（客户端向）
- 细分：App（iOS/Android 双端）、小程序/H5、桌面客户端、平板/嵌入式软体、鸿蒙原生（2026 新兴）、智能硬件（见 07 簇车载）
- 高频附加要求：平台 Guidelines、多分辨率与安全区适配、应用商店物料（icon/开屏/截图）、动效（AE）与原型、交互文档与规范

### 1.4 游戏 UI/UX（UI 与游戏 UX 合并）

- 名称变体：游戏 UI 设计师、游戏界面设计师、游戏 UI 视觉设计师、UX 设计师（C 端游戏社区）、产品 UI 设计师（游戏社区产品）
- 细分：HUD 与系统界面、图标、字体制作、界面包装、游戏社区/平台产品 UI（米哈游社区产品 UI/UX 岗明确分设）
- 高频附加要求：美术功底与手绘（须提供手绘作品）、风格化匹配（二次元/欧美卡通/写实/奇幻）、Unity/UE 落地意识、动态 UI 制作、深度玩家（米哈游 UX 岗要求）

### 1.5 UI 动效设计师（与 03 簇交叉）

- 名称变体：UI 动效设计师、交互动效设计师、动效设计师-产品体验方向
- 高频附加要求：AE/Spine/Rive/Lottie + Figma、UX 动效方法论（功能性/情感化动效）、移动端高保真还原

## 3. 高频能力要求汇总（本簇）

- **必会底座**：Figma（第一主流，Sketch 次之）、PS/AI、版式/色彩/字体、设计规范制定、高保真稿+切图标注、作品集
- **Web 向**：响应式、设计系统/组件库、HTML/CSS 了解（加分）、多浏览器验收、交互文档与原型、数据分析
- **客户端向**：iOS/Android（及鸿蒙）平台规范、多分辨率/安全区适配、应用商店物料、AE 动效/原型、交互流程设计
- **游戏向**：美术功底+手绘作品、图标绘制、风格化匹配、Unity/UE 认知、动态 UI、热爱游戏（深度玩家加分）
- **UX 向（贯通三场景）**：用户研究合作、流程图/原型/交互文档、可用性测试、数据分析、无障碍检查
- **2025-2026 新信号**：AIGC 工具使用进入校招 JD（腾讯）、鸿蒙原生岗位出现（BOSS 2026-05）、技术背景偏好出现（网易交互校招）
- **薪资量级**：实习 100-180 元/天；校招 9-15K；社招中级 12-30K；资深 20-50K；游戏 UI 头部（莉莉丝）30-60K·15薪
