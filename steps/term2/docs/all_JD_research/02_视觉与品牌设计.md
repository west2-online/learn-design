# 02 视觉与品牌设计

> 本簇横跨互联网与实体行业，岗位量巨大、门槛梯度宽（美工到大厂视觉专家），是设计学生就业基本盘之一。
> 与 01 簇的边界：01 聚焦「界面」，本簇聚焦「画面与品牌」；两个簇共享版式/色彩/字体底座，视觉设计师常同时承接品牌与运营物料。

## 1. 细分岗位清单

### 1.1 视觉设计师（产品视觉/大厂通用视觉岗）

- 名称变体：视觉设计师、品牌视觉设计师、创意视觉设计师、视觉设计实习生（UI 方向）
- 大厂视觉岗常横跨产品 UI、运营、品牌三线（腾讯校招视觉设计师：UI+多媒体+品牌，要求 AIGC 工具）
- 细分：产品视觉、商业产品视觉（字节广告）、游戏品宣 3D 视觉

### 1.2 品牌设计

- 名称变体：品牌设计师、资深品牌设计师、品牌视觉设计师、品牌设计经理
- 工作重心：VI/LOGO、品牌识别体系、企业企宣视觉、线下物料
- 高频要求：CorelDRAW（品牌向仍常见）、C4D（品牌视觉渲染）、印刷工艺

### 1.3 IP 设计

- 名称变体：IP 设计师、IP 角色设计师、IP 图库设计师、IP 平面设计师、吉祥物设计
- 产出物：Style Guide Book、表情包、衍生品图库、包装延展、短视频头图

### 1.4 运营与营销设计

- 名称变体：运营设计师、运营设计专家、营销视觉设计师、数字营销视觉设计师、视觉营销设计师
- 工作重心：活动专题页、Banner、闪屏、节日氛围、H5、大促 KV
- 高频要求：手绘、C4D 营销渲染（TCL 等明确要求）、短视频剪辑能力上升

### 1.5 电商视觉设计

- 名称变体：电商视觉设计师、电商设计师、电商美工、淘宝天猫美工、网页美工
- 工作重心：主图/详情页/首页/活动页，大促承接页，店铺装修
- 新兴细分：AIGC 电商（Midjourney/SD/ComfyUI 为硬性要求）

### 1.6 平面与广告设计

- 名称变体：平面设计师、广告设计师、广告创意设计师、创意广告设计师、美工、平面美工
- 细分：印刷物料（VIS/画册/海报/展架）、广告投放创意（banner/H5/落地页）、文化墙设计
- 晋升方向：美术指导（AD）

### 1.7 专项视觉

- 插画师：商业插画、插画原画师（IP 人物）、服装行业插画
- 包装设计师：外包装/结构包装/印刷文件；结构包装设计师需结构设计能力
- 字体设计师：字库公司（书法/平面设计专业，有培养体系）、字体讲师（教育公司）

### 1.8 三维视觉（与 03 簇交叉）

- 名称变体：三维视觉设计师、3D 视觉设计师、C4D 设计师、C4D 渲染设计师、游戏 3D 视觉设计师（品宣方向）
- 应用场景：电商建模渲染、品牌视觉、CG 片头、游戏宣发 KV

## 3. 高频能力要求汇总（本簇）

- **软件三件套**：PS、AI（Illustrator）为核心；品牌向加 CorelDRAW；电商向熟悉淘宝/天猫后台；3D 加 C4D；视频加 AE/PR
- **通用**：美术功底与审美、原创能力、印刷工艺与印刷文件（平面/包装岗）、手绘（营销/插画岗）、文案编撰（运营岗出现）
- **AIGC 新标配**：Midjourney、Stable Diffusion、ComfyUI（电商 AIGC 岗硬性要求；腾讯校招视觉岗列明 AIGC 工具）
- **学历/经验**：本科主流；美工/电商美工可大专；社招普遍 1-3 年起；作品集是所有岗的硬通货
- **薪资量级**：美工 6-9K；平面 8-12K；电商视觉 8-15K；品牌/视觉中级 10-20K；资深/大厂 20-50K；行业均值参考：平面设计约 9.5K（猎聘 2026-08）
