# 06 设计工程与技术

> 本簇是「设计与开发的结合部」：产出物是可用代码/可运行原型，而非静态设计稿。
> 大陆市场的现实：独立「Design Engineer」岗位名很少，相关职能散落在 UI 开发工程师、前端工程师（偏 UI/可视化）、游戏引擎 UI 工程师中。设计生若想切入，需补前端三件套或引擎 UI 知识。

## 1. 细分岗位清单

### 1.1 设计工程师 / UI 开发工程师

- 名称变体：UI 开发工程师、U3D UI 开发工程师、软件 UI 工程师、UI 工程师、前端工程师（UI 方向）
- 工作重心：把高保真设计落地为可运行界面；定义接口交互；撰写设计/开发文档
- 典型技术栈：HTML/CSS/JS、QT、U3D（游戏工具 UI）；React/Vue、Three.js（可视化向）

### 1.2 创意技术（Creative Technologist）

- 大陆几乎无独立岗位名；相关职能散落在「创意工程师、互动开发、沉浸式项目策划」中
- 最接近样本：字节广告创意中心「资深前端工程师（创意方向）」类岗位

### 1.3 可视化工程（与 07 簇交叉）

- 名称变体：前端工程师（可视化方向）、数据可视化开发、Three.js/WebGL 工程师
- 工作重心：大屏/图表/3D 可视化开发；ECharts/DataV/Three.js

## 3. 高频能力要求汇总（本簇）

- **技术栈**：HTML/CSS/JS、QT、U3D、React/Vue、Three.js/WebGL、ECharts/DataV
- **能力**：设计稿还原度、接口对接与文档、组件化开发、与设计/产品协作
- **对设计生的意义**：01 簇「了解实现方式与能力边界」的深化方向；作品集若有可运行 Demo（网页/引擎原型）会显著增强 UI/UX 岗位竞争力
- **薪资量级**：UI 开发/可视化设计 10-15K 起；资深前端（可视化/创意方向）更高
