# 05 产品与用户研究

> 对应 steps 第二学期「产品经理」锚点。
> 本簇对设计背景候选人友好的入口最多：产品助理、AI 产品经理（会用低代码/AI 工具做原型）、游戏策划（重视体验与同理心）均有 JD 明确欢迎设计背景。

## 1. 细分岗位清单

### 1.1 产品经理

- 名称变体：产品经理、产品策划、产品经理培训生（管培生）、产品线经理
- 按用户对象：C 端产品（大疆 DJI FLY、阿里游戏平台、腾讯 AI 产品）、B 端产品（腾讯 VooV、字节云计算、蔚来对内数字化）
- 按领域：AI/大模型、云计算、办公协同 SaaS、智能硬件配套软件、游戏平台、增长/本地生活、内容运营
- 核心职责：需求分析与管理、PRD、竞品分析、数据驱动迭代、跨部门推进（研发/设计/测试/算法）

### 1.2 AI 产品经理（新兴高热度）

- 工作重心：大模型技术落地为产品方案、AI 场景融合、AI 产品全流程闭环
- 两级分化：大厂校招要求「理解大模型+AI 产品经历加分」（腾讯）；小厂直接要求会用 v0/Lovable/Bolt 低代码 + Cursor/Copilot/Claude Code 做原型（Linksome，对设计/UX 背景友好）

### 1.3 产品助理 / 助理产品经理

- 校招入口岗位；职责为需求收集、竞品分析报告、体验把控、数据监控
- 硬技能分化：部分要求 Python+SQL（蔚来 B 端数字化岗）；部分仅要求表达学习能力（UCloud 云计算，计算机专业优先）

### 1.4 产品运营（相邻岗）

- 名称变体：产品运营、增长运营、内容运营
- 样本：搜狐畅游 17173 游戏产品库运营（内容入库/审核）、收钱吧产品运营（增长、本地生活）
- 与产品经理的差异：偏执行与数据运营，不主导产品规划

### 1.5 游戏策划（相邻岗）

- 名称变体：游戏策划、系统策划、数值策划、关卡策划、文案策划、战斗策划、主策划
- 校招样本：4399 游戏策划管培生（专业不限、重视玩家体验与同理心、策划案/拆解/体验报告加分）
- 与设计生的关系：体验设计能力是重要加分项；另有「游戏策划（产品向）」与产品经理职责重叠

### 1.6 用户研究

- 名称变体：用户研究员（UX Researcher）、用户研究工程师、用户研究专家、用户体验研究工程师、汽车人因与用户体验研究经理、人机工效设计师
- 方法论：问卷、深度访谈、焦点小组、可用性测试、用户共创、定性+定量分析
- 专业背景：心理学、社会学、人类学、工业设计、人因工程（高频点名）
- 细分：
  - 互联网用研（小米相机用研、字节经营办公室用研实习、网易游戏用研实习 150-180 元/天）
  - 硬科技/人因用研（问界人因实验室、中汽信息科技、航空研究所人机工效设计师校招；眼动仪/脑电/皮电等多模态设备是硬技能）

## 3. 高频能力要求汇总（本簇）

- **产品经理**：需求分析、数据分析、竞品分析、PRD、项目推进、逻辑思维（几乎每条 JD）；中频：原型/交互设计、用户反馈迭代、商业化意识
- **对设计背景的态度**：友好（Linksome「对用户体验敏感」、大疆「原型设计+UI 资源整合」、鸿合「原型及交互设计」、4399「专业不限+同理心」）；要求技术背景（蔚来 Python/SQL、字节云计算、腾讯 AI 计算机加分）
- **AI 新信号**：低代码原型工具（v0/Lovable/Bolt）与 AI 编程工具（Cursor/Copilot/Claude Code）进入小厂 JD 硬要求；大厂要求大模型理解
- **用户研究**：定性+定量方法论、心理学/人因背景、SPSS、汽车向多模态设备（眼动/脑电）
- **薪资量级**：产品实习 170-200 元/天；校招 15-30K×14-16薪；社招 20-60K；游戏策划校招 15-35K×13薪
