# 07 设计管理与策略

> 本簇是各设计簇的晋升方向与管理支持层：校招几乎不可直接进入（多为 5-10 年经验），但对学习路线设计有「终局目标」参考价值。

## 1. 细分岗位清单

### 1.1 设计管理

- 名称变体：设计经理、设计组长、设计主管、设计负责人、设计总监、设计部总监
- 工作重心：设计团队管理、流程与规范制定、质量评审、项目进度与成本把控、跨部门协调
- 门槛：设计类本科+、多年一线经验；行业差异大（普通设计经理 5-10K 到总监平均 18.9K/月，猎聘统计）

### 1.2 设计系统负责人 / DesignOps

- 现实：大陆公开市场极少独立岗位名；职能内嵌在 UI/交互设计师 JD 中（「建立并维护设计系统/组件库」已高频出现）
- 高阶样本：字节飞书「资深 UX 设计专家-DesignOps」（设计体系落地、全局通用标准、规范制定与更新）
- 对学习者的意义：设计系统能力是 01 簇进阶的差异化技能，而非独立求职目标

### 1.3 设计策略

- 名称变体：设计策略师、前沿策略设计师、UX 设计策略
- 分布：汽车/硬件行业与猎头渠道为主（中山设计策略师、威马前沿策略、上海 UX 设计策略「本科 6 年/硕士 3 年+，主机厂经验优先」）
- 工作重心：趋势研究、竞品分析、设计语言方向制定、高层决策支持、高质量汇报（PPT）

> 无障碍不单列为岗位，已并入第二学期「职业化初步」通用能力（见 `职业化初步_能力提升清单.md`）。

## 3. 高频能力要求汇总（本簇）

- **管理向**：设计流程/规范制定、质量评审、团队建设、进度成本控制、跨部门沟通
- **系统向**：组件库维护、设计规范、多端一致性、Design System 建设
- **策略向**：趋势/竞品研究、设计语言定义、汇报呈现（PPT 被单列）、行业经验（汽车 6-10 年）
- **薪资量级**：设计经理 5-20K（行业差距大）；设计总监平均 18.9K（猎聘 2026-05）；资深 DesignOps/策略岗在大厂更高
