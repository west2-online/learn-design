# 03 动效与多媒体设计

> 本簇是 UI 设计（01 簇）与视频/三维制作之间的桥梁。核心技能栈分层清晰：2D 动效（AE/Spine/Rive）、引擎动效（Unity/UE）、三维（C4D/Blender）、剪辑包装（PR/AE）。
> UI 动效设计师同时属于 01 与 03 两簇；游戏动效（角色/技能/场景特效）属游戏美术，由 Unity 组负责培养，本簇仅保留「游戏 UI 动效」这一 UI 向岗位。

## 1. 细分岗位清单

### 1.1 动效设计师（通用/影视包装向）

- 名称变体：动效设计师、高级/资深动效设计师、AE 动效设计师、二维动效师
- 工作重心：影视内容包装动效、运营活动动效/H5 小游戏界面动效、分镜脚本、提案沟通
- 细分：影视会员包装（爱奇艺）、运营大促动效（字节）、外包驻场（博彦驻美团）

### 1.2 UI / 交互动效设计师

- 名称变体：UI 动效设计师、交互动效设计师、动效设计师-产品体验方向、视觉动效设计师（AI 创新业务）、Rive 交互动效师
- 工作重心：动态交互 Demo、微交互、高保真动效原型、动效规范
- 高频要求：AE + Figma + Lottie/Rive；理解 UX 动效方法论（功能性/情感化）；移动端高质量还原

### 1.3 游戏 UI 动效（01 簇游戏方向交叉）

- 名称变体：游戏 UI 动效设计师、游戏动效设计师（角色/技能动效归游戏美术，Unity 组负责）
- 工作重心：UI 界面动效、角色技能/场景道具动效、引擎落地（Unity/UE）
- 高频要求：Unity（必会）> UE > AE > 3DMAX > Spine；「动效实现效果与性能平衡」是明确考察点

### 1.4 三维视觉 / 三维动效

- 名称变体：三维视觉设计师、C4D 设计师、三维动效设计、品牌动画设计师
- 工作重心：3D 建模渲染、产品动画、CG 片头、电商建模
- 高频要求：C4D（电商/视觉主流）> Blender（新 JD 已出现）> 3dsMax/Maya；脚本语言加分（lua/python）

### 1.5 视频设计与剪辑包装

- 名称变体：视频设计师、AE 视频设计师、剪辑包装师、视频剪辑包装师、短视频制作设计师、游戏视频设计师（买量）
- 工作重心：短视频运营内容、广告视频、游戏买量素材、PV 剪辑包装
- 高频要求：PR+AE 核心，达芬奇/FCP/剪映常见；买量视频要求投放效果导向；会 Spine 加分

### 1.6 MG 动画师 / 多媒体设计师

- 名称变体：MG 动画师、MG 动画合成师、Layout 动画师、多媒体设计师、动态设计师
- 工作重心：MG 动画分镜与动效、多媒体项目三维动画、演示文稿/数据可视化动效

## 3. 高频能力要求汇总（本簇）

- **软件栈**：AE（几乎必会）；UI 向加 Figma+Lottie/Rive；游戏向加 Unity/UE+3DMAX/Spine；三维向 C4D/Blender；视频向 PR+达芬奇/剪映
- **能力**：动画节奏感、镜头语言、色彩把控、提案沟通、动效与性能平衡（游戏岗明确）、作品集
- **新兴信号**：Rive 正在成为交互动效交付新标准（替代 Lottie 趋势）；AIGC 生图/视频岗位进入校招（广州云图 2026 校招 AI 设计师，招 10 人）
- **薪资量级**：MG/剪辑包装 4-13K；C4D 电商 6-9K、品牌/CG 7-18K；UI 动效 15-30K；游戏 UI 动效 20-30K·13薪；大厂高级动效 15-40K
- **实习**：100-250 元/天；学历大专-本科均可；游戏实习接受在校/应届
