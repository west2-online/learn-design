# task6 面试题库（待补充）

01. 入库分流：负责人提供一份包含重复文件、来源不明网图、低分辨率截图、无授权说明的字体与 AI 生成图的样本包，现场完成 Inbox 分流，并说明每个文件的去向与理由
02. 授权判断：一个项目需要一张插画做 Banner，现场从参考库中找出候选，说明哪些可用、哪些需补什么授权记录
03. 归一化：现场将一批命名混乱、多版本重复的文件整理进资产库目录，并补齐元数据
04. 检索与复用：给一个真实需求（如深色背景招新海报需要的可商用装饰素材），现场检索并给出 3 个可用资产及授权说明
05. 新资产入库：现场将一个来源明确的新资产完成 Review -> Normalize -> Register 全流程
06. 更新与废弃：某字体更新了版本且授权范围变更，现场说明影响评估、通知方式、迁移记录与旧版归档
07. 交接：用 5 分钟带新人理解你的资产库结构与取用规则，考察 README 与结构的自解释性
08. 追溯：现场从记录中回溯某次交付使用过的可疑图片的入库时间、来源与当时的决策
09. 归档清理：现场处理一批失效链接与到期授权资产，说明归档、删除与备份策略
10. 批量导入：现场把浏览器的散落收藏批量导入参考库并打上标签
