## 作业

任选一个领域，选择任意数量的任意作品，用 Markdown 格式记录下你对这些作品的：

- 从自身角度出发的感想，包括什么情况看到的这些作品？对其感觉如何？
- 从专业角度出发的分析，聊聊这些作品为什么给你这样的感觉，技法如何？你认为其考虑了哪些因素？存在哪些不足？
- 从未来角度出发的展望，聊聊这些作品给你带来了怎样的启发？你有怎样的相关思考？对这些作品的看法是否有所变化？
- 允许插入或引用其他人的感悟，但需标明出处或给出链接，并附上你对其感悟的看法与评价

> [!TIP]
> 尽量不要在没有图床的情况下插入图片，github仓库本身并不适合存储大图片

字数适中，能表达出你内心所想即可，无需堆砌辞藻与案例。重点在面试时你展露的相关心得体会。

> [!TIP]
> 其实你应该也能看出来，这里的任务基本是要求你写一篇个人分享的博客，因此如果你想仅在提交时在 README 中给出你的博客链接，这也是被允许的，并且我们会根据你对你的博客系统的了解与设计情况，允许你从对应阶段继续考核
