## 学习

### 了解设计规范与原则

> [!IMPORTANT]
> 事实上，这里列出的并不是全部的设计规范与原则，世界上也并不存在一张可以完全囊括所有设计需要考虑的命题的表格。
> 找到实例总结并证明，考虑什么规范可以带来怎样的提升，这才是你真正需要考量的东西，而不是一味死记硬背

1. 目标与限制
    - Purpose: 明确设计需要传达什么、解决什么问题
    - Audience: 理解受众的认知、习惯与使用场景
    - Context: 考虑文化、政策、内容、载体、环境与交付方式带来的限制
2. 视觉要素
    - Point / Line / Shape: 理解点、线、面、轮廓与形状之间的关系
    - Color: 理解色相、明度、饱和度、色彩搭配与颜色语义
    - Typography: 理解字体、字号、字重、行高与字间距对阅读的影响，注意不同语言的字体在视觉传达时的差异性
    - Space / Texture: 理解空间、留白、材质与纹理带来的层次和氛围
3. 构图与关系
    - Grid: 使用网格建立秩序，并允许有目的地打破网格
    - Alignment: 通过对齐建立视觉联系与清晰的阅读路径
    - Proximity: 用距离表达元素之间的归属与关联
    - Scale / Proportion: 使用尺度与比例表达关系、重要性与空间感
    - Balance: 在对称或非对称构图中维持视觉重心
    - Whitespace: 用留白划分内容、控制密度并突出重点
4. 信息与注意力
    - Visual Hierarchy: 通过位置、大小、颜色、明暗等差异建立信息优先级
    - Contrast: 使用明暗、色彩、形状、尺度等对比区分内容，而不只依赖颜色
    - Emphasis: 明确视觉焦点，避免所有元素同时争夺注意力
    - Rhythm / Repetition: 通过重复、间隔与变化形成节奏和阅读预期
5. 统一与变化
    - Consistency: 对同类内容使用一致的视觉语言与组织规则
    - Variety: 在统一规则内引入必要变化，避免机械重复与视觉疲劳
    - Gestalt: 理解接近、相似、连续、闭合、图底等知觉规律
    - 每个不一致都应当有明确目的，而不是来自随意选择
6. 可理解与可感知
    - Clarity: 优先保证信息清晰，再考虑装饰与风格化表达
    - Readability: 控制文字、图形、背景之间的尺寸、间距与对比关系
    - Accessibility: 不只依靠颜色传递信息，照顾不同视觉和认知能力的受众（无障碍）
    - Feedback: 让设计的状态、变化与结果便于观察与理解
7. etc.

### 基础平面设计

借助 Figma 学习基础平面设计

- Grid: 理解网格、对齐、视觉轴线与重心
- Spacing: 建立 4/8px 等间距体系
- Typography: 字号、字重、行高、层级
- Color: Primary / Secondary / Neutral
- Radius: 建立有限圆角等级，体会常用圆角及比例
- Variables: 将颜色、尺寸等抽象为统一变量
- Auto Layout: 用布局规则而非手工坐标组织元素
- Frame -> Visual hierarchy: 体会框架带来的信息优先级
- Pen -> *.svg: 钢笔、贝塞尔曲线及矢量的使用
- etc.

这里自卖自夸一下[@155TuT的旧版考核留痕与心得体会](https://155tut.github.io/2025/10/28/ui-design/)，应该能对你的 Figma 学习有不小的助力

不过值得注意的是，由于本次任务的重点是海报设计，而非旧版的icon绘制与页面设计，因此我们需要做一些艺术字的学习补充：

1. 展示性字体（艺术字）：海报标题是展示性字体的主战场，应作为独立的选型对象对待，我们期望你学习到如下知识:
    - 标题字体挑选、字重对比、中英文搭配与字距调整
    - 描边、渐变、底纹、切割等标题字处理方式
    - 自绘标题字与现成字体的取舍
    - 衬线/无衬线字体的定义与常用领域
    - 不同语言的艺术字设计之间的异同
2. 字体资源与授权:
    - [猫啃网](https://www.maoken.com/): 收录免费商用中文字体
    - [字由](https://www.hellofont.cn/): 字体预览、挑选与管理工具
    - [Google Fonts](https://fonts.google.com/): 开源字体
    - etc.

## 作业

1. 任选一个主题与场景，制作包含海报在内的统一主题的宣传物料至少四种，可从以下列表中挑选：
    - 主视觉海报（必做），用于建立本次设计的核心视觉、信息层级与阅读动线
    - 社交媒体配图，如公众号头图、方形动态配图、竖版信息流图片等
    - 网页或应用中的宣传图，如 Banner、启动页、活动弹窗等
    - 线下宣传物料，如传单、折页、易拉宝、指示牌等
    - 活动相关物料，如邀请函、门票、日程卡、名牌等
    - 周边或包装物料，如贴纸、徽章、手提袋、包装盒等
    - 也可以根据主题选择列表外的真实载体，但需说明其使用场景
    - 同一设计仅改变画布尺寸、裁切方式或少量文字，不视为不同种类；各物料应针对载体和场景重新组织信息，同时保持统一的视觉语言
2. 在开始制作前，完成一份简短的设计说明：
    - 明确 Purpose / Audience / Context：宣传目标、目标受众、使用场景、投放渠道与必要限制
    - 整理必须出现的文案与信息，并按重要程度建立信息层级
    - 确定品牌定位、设计风格、主色、灰阶、采用字体等项目层的统一信息，其中**主视觉标题字**需单独说明选型理由与取舍
    - 为每种物料确定各自的实际尺寸、色彩模式、导出格式与预期观看距离
    - 收集并分析适量参考案例，说明借鉴了什么、舍弃了什么，避免只用“好看”“高级”等词语进行描述
    - 记录字体、图片、图标、纹理等资产的来源和授权；原创或自行拍摄的资产也需注明，自绘的艺术字标题需提交可编辑的矢量源文件
3. 使用 Figma 完成设计，并在源文件中展示以下基础能力：
    - 使用 Frame 分别组织不同物料，并为页面、图层和导出内容使用便于他人理解的命名
    - 使用 Grid、对齐、留白和比例建立版式秩序，使阅读动线和视觉焦点清晰
    - 使用已有或自建组件库完成主题设计，不应每种物料都重新设计或复制粘贴
    - 建立有限且有明确用途的 Spacing、Typography、Color 与 Radius 规则
    - 使用 Variables 统一管理本项目重复使用的颜色、尺寸等数值，并在一处集中展示其名称与用途
    - 在适合的部分使用 Auto Layout，让内容在文案或尺寸变化时仍能保持合理的间距与结构
    - 检查文字与背景对比、字号、图形辨识度等基本可读性问题；不应仅靠颜色区分必要信息
4. 提交内容：
    - 至少四种宣传物料的预览图与按实际用途导出的文件（低保真即可），其中必须包含主视觉海报
    - Figma 项目中需有设计规范的集中展示区，展示使用的网格、颜色、字体、间距、圆角等统一变量及其他必要规则
    - 类似日记的流水账式设计说明与过程记录，简单包括草图或早期方案、参考案例、主要修改和最终取舍即可，无需将自然产生的设计过程包装成复杂流程
    - 一份涵盖可正常访问并具有查看权限的 Figma 链接的 README，说明文件结构、各物料的使用场景、使用方式、资产来源及授权情况
