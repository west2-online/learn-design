## 学习、作业与交付

- 学习部分的课程、参考与知识点可以持续深入，不要求在假期内穷尽所有内容；作业中明确要求的案例、平面练习、三维组件与运营记录是本轮需要完成的产出。
- 建议从 task1 开始积累 task3 的内容发布与反馈；task2 可复用旧项目与已有文章，不必为了分别证明不同能力另起一组无关作品。
- 前两轮共用 [交付组织与图片体积说明](../term1/README.md#前两轮的交付组织)，再按各 task 的具体要求组织 Figma、报告、源码和目标媒介文件。小图、WebP、轻量 SVG 可以提交，不一概禁止预览和导出。
- task1、task2 各有提交入口；task3 沿用 task1 README 中的“寒假轮面试索引”，不新建个人目录或另交一次作业 PR。
