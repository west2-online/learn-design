# task3

> [!TIP]
> 你在 term1 与寒假轮的前几个任务中已经积累了不少作品：海报、界面、排版、主页、Skill……但它们散落在各次提交里，无法被快速理解。
> 作品集不是作品的堆砌，而是用结构化的叙事告诉别人：你面对什么问题、你如何思考、你做出了什么、你学到了什么。
> 本阶段你要把这些作品重新组织为案例，并在博客上建设作品集页面，让每个作品都能独立“开口说话”

## 学习

### 作品集规划

1. 案例选择
    - 从 term1 至今的作品中挑选 3 ~ 5 个案例，标准：完整度、代表性、与个人定位的相关性
    - 宁缺毋滥：一个完整案例的叙事价值，高于十个截图拼贴
2. Case Study 结构
    - 背景与问题：项目的来由、要解决的问题与约束条件
    - 目标与角色：你的目标是什么、你负责什么
    - 调研与思考：你收集了什么依据、如何分析
    - 方案与过程：方案如何形成，经历了哪些取舍与迭代（保留草图与中间版本）
    - 结果与验证：最终产出、如何被验证或使用
    - 反思：哪里做得好、哪里不足、如果重来会怎么做
3. 叙事方法
    - 一个案例解决一个核心问题，围绕它组织内容，而不是平铺全部过程
    - 用真实过程记录支撑结论（草图、截图、数据、反馈），而不是事后包装
    - 区分事实、他人反馈与自己的假设（与 term1/task4 的调研要求一致）
4. 作品集页面设计
    - 首页：案例的展示方式（缩略图、标题、一句话摘要）与筛选方式
    - 案例详情页：长文排版、图片规则与章节导航
    - 与博客的视觉系统保持一致（task1 的 Token 与组件应被复用）
5. 参考视频
    - [25分钟点评50份设计作品集｜作品集避坑指南](https://www.bilibili.com/video/BV1gjgv61EZm/)
    - etc.

### 设计进阶

> [!TIP]
> 作品集的质量上限取决于你的设计功力。本阶段在整理旧作品之余，为下一步的视觉表达补充两个新方向：
> 一是回到平面设计更早、更基础的部分，补上比例、几何构造与字形的基本功；二是向三维设计迈出第一步，为作品集和个人品牌扩展新的视觉语言。
> 两者都可以配合 AI 完成工具与实现层面的工作，但基础的几何构造与理解、以及三维背后的计算机图形学原理，都需要你自己完成学习

#### 平面设计进阶

> [!IMPORTANT]
> term1 的平面设计学习以现代数字工具为主线（Grid、Spacing、Token、Auto Layout……），这些规范大多来自印刷时代的经验总结，容易知其然而不知其所以然。
> 本部分回到平面设计更早、更基础的东西——形式、比例、几何构造、字形与印刷媒介，补上数字工具出现之前的设计基本功，再把它们映射回今天的屏幕与交付场景；这些知识不受某一种工具与风格限制，却完全可以成为你最本质的直觉。
> 本部分的内容并不要求在假期内学完，持续提升才是任务，挑选自己较为薄弱或感兴趣的的方向学习

0. 为什么回到更基础的部分
    - term1 解决的是“如何高效、可维护地排布画面”，本部分回答的是“画面为什么这样排才成立”
    - 比例、网格、字体排印等现代规范，都能追溯到几何构造与印刷工艺；理解了源头，才能有目的地打破规则（呼应 term1/task2 的要求）
    - 这部分内容与工具无关：在 Figma 里用参考线，还是纸笔尺规，学的是同一件事
1. 比例与几何构造
    - 黄金比例、根号比例（√2 / √3）、Fibonacci 数列、等分比例等经典比例系统，理解比例如何带来视觉秩序
    - 比例在版面中的体现：纸张与画幅、页边距与版心、字号与行距、图形与留白之间的关系
    - 尺规作图的基础构造：垂直平分、等分线段、正多边形、相切圆、内切与外接等
    - 法线、切线与曲率：理解垂直关系、相接方式与轮廓连续性如何帮助建立结构
    - 体会“用几何方法构造比例”，而不是依赖数值凑整；现代软件的参考线，本质上就是这些几何构造的数字化
    - 比例不是让作品自动成立的公式：比较不同构造方案并说明选择依据，不要在作品完成后强行叠加黄金比例包装过程
2. 形态、构成与视觉知觉
    - 点、线、面与正负形：理解形状、轮廓、方向、密度、肌理与留白之间的关系
    - 圆、方、三角等基础几何形的组合、分割、重复、渐变、旋转与变形，体会形式如何形成节奏
    - 对称 / 非对称、稳定 / 张力、统一 / 变化、秩序 / 随机等构成关系；用视觉重心判断平衡，而不只看数值是否相等
    - Gestalt：接近、相似、连续、闭合、共同区域与图底关系，理解人如何把分散元素组织为整体
    - Optical Correction：几何居中不一定等于视觉居中；学习曲线 overshoot、图形面积补偿、悬挂标点与光学对齐
    - 标志与图形规范制图（grid construction）：只在几何约束确实参与设计时展示构造，不以复杂辅助线代替辨识度与概念
3. 网格、画幅与版面系统
    - 区分 manuscript / column / modular / hierarchical grid，并理解列、栏间距、模块、基线网格与版心的作用
    - 从内容建立网格：先判断信息类型、阅读顺序、图片比例与媒介限制，再决定栏数和模块，而不是先套模板
    - 建立 Typography Scale、Baseline Grid 与间距节奏，使标题、正文、注释、图片和说明文字共享可解释的结构
    - 学习跨页、系列海报与不同尺寸物料中的连续性：哪些规则保持不变，哪些可以随 Context 调整
    - 有目的地打破网格：偏移、跨栏、出血与尺度突变应服务于信息层级或情绪，而不是为了显得“有设计感”
4. 字形、文字与微观排印
    - 字形解剖：字怀、衬线、x-height、cap height、基线、字干、字腕与字腔等基本概念
    - 字母比例与构造：从罗马大写体（Trajan 碑文）、印刷活字到现代字体与 Variable Font 的演变脉络
    - 中文基础：间架结构、字面、重心与中宫；理解中文并不是把西文排印规则简单放大一倍
    - 字体分类、字族与字重：依据内容气质、阅读距离、字符覆盖、屏幕 / 印刷表现与授权选择字体，而不只依据个人喜好
    - Macro Typography：标题与正文的分工、层级、栏宽、行长、对齐方式以及图文关系（与 term1/task2 的艺术字学习互相印证）
    - Micro Typography：kerning、tracking、leading、标点挤压、段落缩进、孤行寡行、数字与 OpenType Feature 等细节
    - 中西文混排：处理字面大小、基线、字重、标点、数字与空格的差异，并检查真实文案而不是只看占位文字
    - 推荐观看: [你可能正在被劣质字体毒害 | Andrew Lam](https://www.bilibili.com/video/BV1hddGBfEnb/)
5. 色彩、图像与视觉叙事
    - 从色相、明度、饱和度继续深入到色彩相对性：同一颜色会因面积、邻色、背景与观看环境产生不同感受
    - 用明度结构先保证层级与可读性，再处理冷暖、互补、类似色和品牌语义；必要信息不能只靠颜色区分
    - 区分 RGB / CMYK / Lab / Spot Color、色域与 ICC Profile，理解屏幕发光与纸张反光导致的颜色差异
    - 图像选择与处理：裁切、视线、景别、比例、蒙版、网点、Duotone 与颗粒会共同改变信息和情绪
    - 建立图像与文字的关系：重复、补充、对比、隐喻或反讽；避免图片只作为填满空白的装饰
    - 理解符号、图标与视觉隐喻的文化语境，区分“看见了什么”与“它被解释成什么”，避免无依据地挪用符号
6. 媒介、印刷与交付
    - 区分 Vector / Raster、PPI / DPI、像素尺寸与物理尺寸，依据最终观看距离决定图片精度与最小文字大小
    - 学习裁切尺寸、出血、安全区、裁切标记、套印与叠印、黑色文字与富黑等基础印前概念
    - 了解常见纸张、装订与印刷方式如何反过来影响颜色、网格、跨页和成本；条件允许时进行一次纸样或打印打样
    - 为不同用途选择 SVG / PNG / JPEG / PDF 等格式，检查字体嵌入、透明效果、图片压缩、色彩空间与导出倍率
    - 在真实尺寸、缩略图、屏幕与打印样张中分别验收；源文件、链接与 Preview 正常并不代表最终成品一定正确
7. 设计史、方法与评析
    - 了解 Arts and Crafts、Bauhaus、International Typographic Style、Postmodern / New Wave 等脉络，观察技术与社会环境如何改变视觉语言
    - 学习经典作品不是收集“风格关键词”：记录作品的年代、媒介、受众、限制与传播目的，再判断哪些方法仍适用于今天
    - 区分装饰、功能与表达：形式可以承载层级、语气、身份与立场，不应只用“高级”“简约”“有冲击力”评价作品
    - 使用“描述 -> 分析 -> 解释 -> 评价”的顺序进行 Critique，先陈述可观察事实，再说明判断与证据
    - 检查可读性、文化偏见、素材授权与误导性表达；设计成立不仅是视觉问题，也包括它如何影响真实的人
8. 学习方法
    - 临摹与分析并重：拆解经典作品的版式、比例、色彩与字体构造（延续 term1/task1 的分析方法），说明借鉴了什么、舍弃了什么
    - 几何构造练习：用参考线复原经典版式、标志或字形，保留完整的辅助线过程，并补充光学修正前后的对照
    - 限制条件练习：使用同一份真实内容，分别以单栏 / 多栏、黑白 / 彩色、屏幕 / 印刷等限制完成多个方案，比较规则如何影响结果
    - 与 AI 协作：可用 Agent 辅助检索资料、梳理知识脉络与解释概念，但构造、排版、打样、比较与最终判断由自己完成
    - 与 term1 衔接：把这些基础映射回 Figma 的 Grid / Spacing / Typography / Color，说明现代工具的规则从哪里来

#### 三维设计入门

1. 图形学基础
    - 从 [GAMES101: 现代计算机图形学入门](https://csdiy.wiki/%E8%AE%A1%E7%AE%97%E6%9C%BA%E5%9B%BE%E5%BD%A2%E5%AD%A6/GAMES101/) 中挑选对应章节自学，推荐至少覆盖：
        - 变换（Transformation）：模型 / 视图 / 投影变换与 MVP 矩阵
        - 光栅化（Rasterization）：三角形、采样与抗锯齿、深度测试
        - 着色（Shading）：Blinn-Phong 模型、纹理映射与插值
        - 几何（Geometry）：曲线曲面与网格表示
        - 光线追踪（Ray Tracing）：Whitted-Style 与辐射度量学简介
    - 这一部分需要自己完成学习并记录理解，不以 AI 总结代替；可用 Three.js 或渲染器中的对应概念互相验证
2. Three.js
    - 用代码组织三维场景，参考以下资料：
        - [three.js 官方文档](https://threejs.org/docs/)
        - [three.js journey](https://threejs-journey.com/)
        - etc.
    - 将 GAMES101 的概念与 Three.js 对应起来：
        - MVP 变换 → Camera
        - 着色 → Material
        - 网格 → Mesh / Geometry
    - 目标：制作可嵌入博客与作品集的 3D 视觉组件（如首页装饰、案例头图背景）
    - 可配合 AI 编写代码，但需理解相机位置、灯光类型、材质属性等关键参数的作用，能向 AI 精确描述修改需求
3. 学习目标
    - 不必完成完整建模管线，而是：制作与个人品牌相符的 3D 视觉资产、理解材质与光影的基本控制、能将其嵌入网页
4. etc.

## 作业

1. 整理作品并完成案例选择：
    - 梳理 term1 与寒假轮至今的全部作品，建立作品清单（名称、时间、类型、亮点、不足）
    - 挑选 3~5 个案例，说明选择理由与放弃理由
2. 为每个案例撰写结构化 Case Study：
    - 覆盖背景与问题、目标与角色、调研与思考、方案与过程、结果与验证、反思六个部分
    - 保留并引用真实过程记录：草图、中间版本、用户反馈、修改前后对照等
    - 每个案例明确一个核心问题，围绕它组织叙事
    - 区分事实、他人反馈与自己的假设；引用他人内容需标明出处
    - 案例中使用的字体、图片、图标等第三方资产需记录来源与授权
3. 建设作品集页面：
    - 在博客上完成作品集首页与至少一个案例详情页的落地
    - 复用 task1 建立的 Design Token 与组件，说明新增了哪些组件及原因
    - 案例详情页的长文排版、图片规则与章节导航需单独设计并说明
    - 在移动端与深浅色模式下验证阅读体验
4. 完成设计进阶的学习与产出（平面设计进阶 + 三维设计入门）：
    - 平面设计进阶（回到更基础的部分）：
        - 学习并记录：比例与几何构造、形态与 Gestalt、网格与版面系统、字形与微观排印、色彩与图像、印刷与导出基础；不要求平均用力，但需说明本次作品重点解决了哪些问题
        - 完成至少一次几何构造练习：用参考线复原经典版式、标志或字形，保留完整的辅助线与比例构造过程，说明使用了哪些比例与几何关系
        - 为构造练习补充一次光学修正：展示纯几何结果与视觉调整结果，说明为什么数值正确仍可能看起来不平衡
        - 产出一件运用这些基础的作品（海报 / 封面 / 标志等），说明哪些比例、网格、字体、色彩与图文规则被使用，以及为什么
        - 明确作品的目标媒介与真实尺寸；至少完成缩略图、实际尺寸与目标媒介三种检查，若面向印刷还需检查图片精度、色彩空间与字体嵌入
        - 使用“描述 -> 分析 -> 解释 -> 评价”完成一次作品自评或同伴 Critique，区分可观察事实、个人判断与他人反馈，并据此完成至少一轮修改
        - 说明这些更基础的知识与 term1 所学 Grid / Spacing / Typography / Color 之间的衔接：现代工具的规则从哪里来
        - 记录字体、素材的来源与授权；AI 生成或辅助的素材需标注模型与生成时间，不得直接使用 AI 成品
    - 三维设计入门：
        - 使用 Blender / Spline 等工具制作至少一个 3D 视觉资产，用于作品集或个人品牌（如案例头图、首页装饰），说明其与个人 VI 的关系：配色、气质如何统一
        - 从 GAMES101 中挑选章节（至少覆盖变换、光栅化、着色）自学并提交学习笔记：概念理解、与 Three.js / 渲染器中的对应关系、验证过程；不以 AI 总结代替自己的学习记录
        - 使用 Three.js 完成至少一个可嵌入网页的 3D 视觉组件（如首页装饰、案例头图背景）；可配合 AI 编写代码，但需能说明相机、灯光、材质等关键参数的作用，并能向 AI 精确描述修改需求
        - 检查使用的模型、贴图、字体等资源的来源与授权；AI 生成资产需标注模型与生成时间
        - 记录学习过程：教程、遇到的问题与解决方式
