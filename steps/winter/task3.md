# task3

> [!TIP]
> 经过 `term1/task5` 与寒假轮前两个任务，你的个人品牌已经有了“家”（博客）、“橱窗”（各平台主页）与“展品”（作品集）。
> 但如果它们长期没有新内容，就会慢慢失去生气。本阶段你要做的是让内容真正流动起来：
> 在一个或多个平台持续发布与个人定位一致的内容，用真实反馈检验你的设计，并把内容生产沉淀为可持续的工作流。
> 运营并不在一朝一夕，本任务只是作为你开始的帮助

## 学习

### 内容规划

1. 账号定位
    - 明确你发布内容的平台、方向与目标受众，并与个人品牌定位保持一致
    - 设计内容栏目：如设计思考、作品拆解、工具分享、学习记录等，说明取舍
2. 选题方法
    - 从真实学习中找选题：任务中的心得、踩坑、作品过程都是素材
    - 观察同方向的优秀账号，分析其选题、标题与封面，但避免模仿其表达
3. 内容生产工作流
    - 复用资产库（term1/task6）与个人 VI（task1）：封面、头图、排版应模板化
    - 建立从 `选题 -> 素材 -> 制作 -> 检查 -> 发布 -> 复盘` 的流程
    - 使用 AI 辅助生产时（延续 term1/task5 的要求）：保留记录、检查授权、人工验收
4. 平台规则与版权
    - 发布前了解平台的内容规范与图片尺寸
    - 所有素材确认来源与授权，引用他人内容需注明出处
5. 数据与迭代
    - 学会阅读基础数据：阅读量、互动、完读率等，区分“好看的数据”与“真实反馈”
    - 依据反馈调整选题与视觉，而不是追逐流量或纯凭直觉
6. 参考账号
    - [bilibili/反光的邬科](https://space.bilibili.com/275571673)
    - [bilibili/oooooohmygosh](https://space.bilibili.com/38053181)
    - [bilibili/布陆](https://space.bilibili.com/5342410)
    - etc.
7. etc.

## 作业

1. 制定运营计划：
    - 选定至少一个平台与内容方向，说明与个人定位的关系
    - 规划内容栏目与发布节奏（寒假期间至少发布 3 篇/条，质量优先，数量可自行评估）
    - 明确目标：你希望内容带来什么（关注、机会、反馈还是记录），并说明如何衡量
2. 生产并发布内容：
    - 使用个人 VI 与模板完成每篇内容的封面、排版等视觉部分
    - 每条内容需经过发布前检查：错别字、链接、图片授权、平台尺寸与深浅色显示
    - 保留每篇内容的生产过程记录（素材、草稿、修改、AI 使用记录）
    - 推荐为图文形式，也可以剪辑为简单的视频
    - 推荐自己读稿，而不是采用 AI 配音（仅从账号亲和度角度作为指导意见，并不是强制要求）
3. 复盘与迭代：
    - 记录发布后的数据与真实反馈（评论、私信、朋友反馈等）
    - 分析数据与反馈：哪些选题或视觉有效、哪些无效，为什么
    - 根据复盘调整选题方向或视觉模板，并说明调整依据
    - 反思内容生产的成本：哪些环节可以模板化、哪些环节消耗最大
4. 沉淀工作流：
    - 将封面模板、排版规则、检查清单等整理为可复用资产（可放入个人资产库）
    - 输出一份内容生产 SOP，让“下一次发布”的成本低于“上一次”
5. 提交内容：
    - 这是寒假轮的最后一个任务，仅作为 `winter/task1` 个人品牌与多平台主页的持续运营延伸，因此仅需要在面试中展示与讲解，不设置新的个人提交目录
